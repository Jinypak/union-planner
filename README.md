# 유니온 육성 플래너 v0.2

넥슨 Open API로 계정 캐릭터를 불러와, 일퀘·몬파·에픽던전·주간 미니게임을 SSS(250)·링크 3렙(285)·유니온 레벨 목표에 맞춰 배분하는 정적 페이지입니다. 기본(직접 클리어)과 MVP 블랙(퀵패스·리조트) 두 가지 모드를 지원합니다.

- API 키는 이용자 브라우저(localStorage)에만 저장됩니다.
- 빌드 없이 정적 파일로 동작합니다.

## 구조
- `index.html` — 화면 마크업
- `css/style.css` — 스타일 (라이트/다크 테마 토큰)
- `js/data.js` — 레벨별 필요 경험치·리조트 경험치 표
- `js/app.js` — API 조회, 배분 시뮬레이션, 렌더링
