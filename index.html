유니온 육성 플래너 v0.1 · 2026-10-28

캐릭터 이름으로 계정 전체를 불러와, 일퀘·몬파·에픽던전·주간 미니게임을 SSS(250)·링크 3렙(285)·유니온 레벨에 어떤 순서로 나눌지 계산해요. 기본은 직접 클리어 기준이고, MVP 블랙 탭은 퀵패스·리조트까지 넣어 계산해요.

API 키 소유 계정의 캐릭터만 전체 조회할 수 있어요. 키를 넣고 캐릭터 이름으로 조회하세요.
계산 설정

던전은 계정당 주 1회, 4개 중 3개까지이고, 한 캐릭터는 주에 던전 1개만 갈 수 있어요. 캐릭터를 정하면 그 캐릭이 가고, '자동'은 남은 자리를 자동 배정 방식으로 채워요. 지정이 3개를 넘거나 같은 캐릭을 두 번 지정하면 위에서부터 먼저 지정한 것만 적용돼요.

일퀘·몬파 기본 경험치는 보내주신 표(보너스 0%) 값이에요. 이벤트 스킬의 몬파·일퀘 보너스는 조회할 때 대표 캐릭터의 0차 스킬에서 읽어 [이벤트] 칸에 자동으로 채워요. 직접 고친 값은 다음 조회 전까지 유지돼요. 일자별 계획은 오늘부터 7일씩 1주차로 묶고, 썬데이 보너스는 실제 일요일에 적용해요. 아케인리버 %는 여로~리멘(테네브리스 포함), 그란디스 %는 세르니움 이후에 적용돼요. 에픽던전은 레벨별 % 표(기본·1단계·2단계)를 써요. 어센틱 일퀘 심볼은 23주년 1.5배 반영값(세르니움 30, 나머지 15)이에요. 탈라하트·기어드락도 15개예요. 일퀘(아케인 6·테네브리스 3·그란디스)는 지역마다 하루 2캐릭, 주간 미니게임은 지역마다 주 1회씩 2캐릭까지 진행해요. 지역마다 자리가 따로라서 서로 경쟁하지 않아요. 직접 사냥·쿠폰(5배·70%)은 계산에 넣지 않았어요.

조회하면 여기에 계정 요약, 캐릭터, 퀵패스 배분표가 나와요.
